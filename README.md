# DS5500-xG-Project

Expected Goals (xG) is a metric used in various sports to estimate the number of goals a player or team would, on average, score based on certain in-game events. It considers a variety of factors, including possession, number of shots, number of shots on target, which body part was used to shoot, etc., but leaves room for enhancement through considering additional context. That said, it may be beneficial to actually restrict the number of attributes a model considers in order to make the metric more interpretable to casual fans. This idea offers a different approach we could take with our project. Optimizing upon the current metric would be beneficial to football players, coaches, and fans, and potentially fans in other sports if our results generalize beyond football.

We aim to develop a machine learning pipeline with a logistic regression model that assigns probabilities (of a goal) to each shot taken. The primary dataset we have identified so far, StatsBomb open data, contains extensive information about in-game events (e.g. passes, shots, goals, etc.) that we will use to train our model. Our dataset is, however, limited in two ways: first, the publicly-available data is just a subset of all their event-level data, and second, the available subset is imbalanced between the leagues and teams it covers. Evaluation metrics will be determined as we make progress, but will likely include accuracy, precision, recall, and F1-score.
