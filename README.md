# DS5500-xG-Project

Expected Goals (xG) is a metric used in football to estimate the number of goals a player or team would, on average, score based on certain in-game events. It considers a variety of factors, including possession, number of shots, number of shots on target, which body part was used to shoot, etc., but leaves room for enhancement through considering additional context. Optimizing the current metric would be beneficial to football players, coaches, and fans, and potentially fans in other sports if our results generalize beyond football.

We aim to develop a machine learning pipeline with a logistic regression model that assigns probabilities (of a goal) to each shot taken. Our primary dataset will be Hudl’s StatsBomb open data [1], which contains detailed records of in-game events (e.g. passes, shots, goals, etc.) that we will use to train our model. So far, this is the most robust publicly available dataset we have found, but we are continuing to explore potential additional datasets after identifying limitations in our preliminary results. Evaluation metrics will be determined as we make progress, but will likely include accuracy, precision, recall, and/or F1-score.
